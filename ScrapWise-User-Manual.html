1. What ScrapWise Is For

ScrapWise is used to manage junkshop operations in one place. It helps the team record purchases, sales, inventory, truck deliveries, cash operation, attendance, payroll, and reports.

The system is designed for multiple branches. Admin users can see and manage more areas. Staff users usually work with daily transactions, inventory, deliveries, and attendance. Payroll users work with employees, cash advances, and payroll.

Important: Always choose the correct branch, date, material, customer, supplier, and employee before saving a record.

2. Login, Logout, and Language

Login Open ScrapWise, enter your email or username, enter your password, then click Sign in. The system will open the correct access based on your user role.
Logout Click Log out at the bottom of the sidebar when you are done.
Language Use the EN and FIL buttons in the sidebar to switch between English and Filipino where available.

4. Dashboard

The dashboard is the first summary page after login. It shows a quick view of the business.

  • Purchases shows the total value and weight bought.
  • Sales shows the total value and weight sold.
  • Gross profit shows the estimated income view.
  • Inventory value shows the current estimated stock value.
  • Pending payments shows open balances that still need collection or payment.
Use the dashboard to check the overall condition of the shop before looking at detailed records.

5. Attendance

Use Attendance to add employee time in and time out. The employee list is based on the selected branch.

  1. Select the Date.
  2. Select the Branch.
  3. Select the Employee.
  4. Enter Time in.
  5. Enter Time out when the employee finishes duty.
  6. Select the status: On duty or Completed.
  7. Add notes if needed, then click Save attendance or Save changes.

Cash Advance Before Time Out

If an employee asks for a cash advance during the day, use the cash advance area in Attendance. Enter employee, date, amount, reason, and status, then save.

Completed attendance is used later in Payroll to calculate regular hours and overtime hours.

6. Review Attendance

Use Review Attendance to see who was on duty for a selected branch and date range.

  • Select All branches or one branch.
  • Select Date from and Date to.
  • Review employee, branch, date, time in, time out, regular hours, overtime hours, status, and notes.
  • Click Edit if a time in or time out needs correction.
  • Click Download Excel to export attendance records.

7. Cash Operation

Cash Operation is used to open the daily operating fund, record added or removed cash, close the operation, and print the cash receipt.

Starting Amount

  1. Open the Starting amount tab.
  2. Select the operation date and branch.
  3. Enter the starting cash amount.
  4. Add opening notes if needed.
  5. Click Open operation.

Paid In

Use Paid in when adding cash to the fund. Example: additional fund from owner.

Paid Out

Use Paid out when removing cash for expenses. Example: transportation or supplies.

Close Operation

  1. Return to Starting amount.
  2. Review starting cash, cash payments, purchases, paid in, paid out, and expected cash.
  3. Enter the actual cash counted in Close cash.
  4. Click Close operation.
  5. Confirm the closing message.
  6. Print the receipt if needed.
After closing, the record is saved in Operational history and the cash operation area is ready for the next operation.

8. Transactions

Use Transactions to record buying scrap from suppliers and selling scrap to customers.

New Transaction

  1. Select the date and branch.
  2. Select Purchase or Sale.
  3. Select the customer or supplier.
  4. Select the scrap material.
  5. Enter weight in kilos. The weight must be greater than zero.
  6. Enter price per kilo.
  7. If the agreed price is different for this seller, enter Price per demand.
  8. Select payment status: Paid, Unpaid, or Partial.
  9. Review total and balance, then click Save transaction.

Same Customer, Multiple Materials

If the same customer or supplier has another material, check Process another transaction with the same customer. After saving, the form keeps the same customer so you can add the next item faster.

Edit, Delete, and Print

  • Click Edit to correct a saved transaction.
  • If you edit and change the date, the system may use Save as so the old record stays safe and a new dated record is created.
  • Click Delete to remove a wrong transaction.
  • Click Print for an individual transaction receipt.
  • Click Print customer receipt to print all transactions for one customer or supplier.

9. Inventory

Inventory shows current stock based on all stock movement records. Purchases add stock. Sales and deliveries reduce stock.

Stock Position

Shows material, current stock, estimated value, and location. Use the material and location filters to focus the list.

Stock Movements

Shows every stock movement, including truck plate number, driver, delivery status, and notes when related to a delivery.

List of Materials

Shows material stock by location and groups related transactions by day.

Downloads and Adjustments

  • Click Download Excel to export inventory.
  • Admin users can use Manual adjustment to correct stock, with a reason.

10. Deliveries

Use Deliveries when scrap is loaded into a truck and moved or sold to another destination.

New Delivery

  1. Select the date and source branch.
  2. Select the destination from the dropdown list.
  3. Enter truck plate number and driver name.
  4. Select status: Pending, In transit, Completed, or Cancelled.
  5. Select scrap material.
  6. Enter loaded weight. The system should not allow a load greater than available inventory.
  7. Enter delivered weight when the delivery is completed.
  8. Save the delivery.

Same Truck, Multiple Scrap Loads

If the same truck carries another scrap material, check Process another scrap material with the same truck. This helps the user add, add, add without repeating truck details.

Delivery Records

  • Use filters for status, driver, plate number, and location.
  • Click Edit to correct a delivery.
  • Click Print to print the delivery record. The operator name appears on the printout.
  • Click Download Excel to export delivery records.
  • Completed deliveries show discrepancy and calculated loss.

11. Customers and Suppliers

Use Customers/Suppliers to maintain the names used in transactions.

  • Select whether the contact is a customer or supplier.
  • Enter name.
  • Contact number, address, and notes are optional.
  • Click Save.
  • Click Edit beside a saved record to update it.

12. Maintenance Pages

Materials/Prices

Admin users maintain material names, categories, buying prices, selling prices, unit, and status. Transactions keep the price used at the time, so old records remain correct even if the price list changes later.

Location Maintenance

Admin users maintain branch or location records. Contact number is optional. This page supports multiple branches.

Destination Maintenance

Admin users maintain delivery destinations such as buyers, warehouses, processors, or other delivery contacts. These destinations appear in the delivery dropdown list.

13. Employee Maintenance

Use Employee Maintenance to maintain employee payroll information.

  • Employee name
  • Branch
  • Position
  • Salary type: daily or monthly
  • Rate
  • SSS number
  • Pag-IBIG number
  • Other benefits
  • Start date
  • Status

The employee record connects to Attendance and Payroll.

14. Payroll

Payroll calculates employee income, deductions, cash advance deductions, and net pay.

New Payslip

  1. Select payroll period from and to.
  2. Select pay date.
  3. Select employee.
  4. The system uses employee rate and attendance records to help calculate basic salary and overtime.
  5. Enter other income and deduction amounts if needed.
  6. Review Gross Pay, Deductions, and Net Pay.
  7. Click Calculate and save.

Payroll Result Tabs

TabPurpose
Payroll summaryShows payslips. Use Edit to correct, Print payslip to print, and Download all payrolls for export.
Cash advance recordsShows cash advances. Use Edit to correct a cash advance.
Attendance payroll trackerShows attendance records used for regular and overtime hours.

New Cash Advance

At the bottom of Payroll, add a cash advance by selecting employee, date, amount, reason, and status. The amount is included as a deduction when the payroll period includes that date.

15. Reports

Reports allow users to filter records by date and branch, then view or export results.

  1. Select From date and To date.
  2. Select branch or All branches.
  3. Open the needed report tab.
  4. Click Export CSV if available.
Report TabWhat It Shows

PurchasesDaily purchase report.
SalesDaily sales report.
InventoryInventory report.
Income / ProfitAdmin-only income and profit report.

16. Users

Admin users can add, edit, and delete user accounts.

  • Staff can handle normal operations.
  • Payroll/Admin Staff can access payroll and employee maintenance.
  • Admin can access all admin maintenance pages and restricted reports.
Only give admin access to trusted users.

17. Suggested Daily Process

Before Opening

  • Login.
  • Open Cash Operation.
  • Enter starting amount.
  • Check the dashboard.

During Operation

  • Record purchases and sales.
  • Use same customer checkbox for multiple materials.
  • Record paid in and paid out cash.
  • Add attendance and cash advances if needed.
  • Record deliveries when trucks are loaded.

Before Closing

  • Review transactions.
  • Check inventory.
  • Complete employee time out.
  • Close cash operation.
  • Print needed receipts and reports.

18. Tips and Common Reminders

  • Do not save a transaction with zero or blank weight.
  • Use Edit when correcting a mistake instead of creating a duplicate.
  • For delivery, check available stock before saving loaded weight.
  • Use dropdown lists for branch, customer, supplier, material, and destination whenever available.
  • Close cash operation only after counting actual cash.
  • Cash advance deductions follow the payroll period date range.
  • Download Excel or CSV files before sharing reports outside the system.
  • Do not click Reset demo data during actual work.
Data reminder: This current app is a browser-based MVP. Make sure real production use has proper login security, database backup, and user access controls before using it for live business records.
